# 配置参考

## 环境变量

WPanel 通过环境变量配置，全部有合理默认值，**开箱即用**。

### 控制服务（`server.mjs`）

| 变量 | 默认 | 说明 |
|---|---|---|
| `WPANEL_PORT` | `8766` | 控制服务监听端口 |
| `WPANEL_DISTRO` | `Ubuntu` | 目标 WSL 发行版名，需与 `wsl -l -v` 中的 `NAME` 一致 |
| `WPANEL_ROOTS` | `/home` | 文件管理允许的根目录，逗号分隔，例如 `/home,/srv,/opt/data` |
| `WPANEL_COMPOSE_DIR` | 发行版默认用户 `$HOME/compose` | Compose 项目扫描目录；必须是**不含空格与引号**的绝对路径 |
| `WPANEL_UI_ORIGINS` | `http://localhost:8765,http://127.0.0.1:8765` | 允许的前端来源，逗号分隔。改 UI 端口时**必须同步改这里**，否则浏览器请求全部 403 |
| `WPANEL_ALLOWED_HOSTS` | `127.0.0.1:8766,localhost:8766` | 控制服务可接受的 `Host` 头，逗号分隔。改 `WPANEL_PORT` 后需同步 |
| `WPANEL_STOP_UNITS` | 空 | 「停止 Docker」与「安全关闭 WSL」时额外一并停止的 `.service` 单元，逗号分隔 |
| `WPANEL_STORE_REPO` | `https://github.com/1Panel-dev/appstore` | 应用商店模板源默认值（界面里可覆盖） |
| `WPANEL_STORE_BRANCH` | `main` | 应用商店模板源分支默认值 |

### 前端（构建时注入）

| 变量 | 默认 | 说明 |
|---|---|---|
| `NEXT_PUBLIC_WPANEL_API` | `http://127.0.0.1:8766` | 前端要访问的控制服务地址。**在 `npm run build` 时注入，改完必须重新构建** |

### 组合示例

换成 Ubuntu-24.04、UI 走 9000、控制服务走 9001：

```powershell
$env:WPANEL_DISTRO = 'Ubuntu-24.04'
$env:WPANEL_PORT = '9001'
$env:WPANEL_ALLOWED_HOSTS = '127.0.0.1:9001,localhost:9001'
$env:WPANEL_UI_ORIGINS = 'http://localhost:9000,http://127.0.0.1:9000'
$env:NEXT_PUBLIC_WPANEL_API = 'http://127.0.0.1:9001'

npm run build
node server.mjs                                   # 控制服务
npm run start -- --hostname 127.0.0.1 --port 9000 # 前端
```

> 注意 `WPANEL_PORT` 只改控制服务端口，前端端口由 `vinext start --port` 决定，两者都要与白名单对齐。

## `data/wpanel.local.json`

运行时配置，**不进 git**（`.gitignore` 已忽略整个 `data/`）。文件不存在时全部走默认值。

```json
{
  "services": [
    { "key": "postgresql", "name": "PostgreSQL", "unit": "postgresql.service" },
    { "key": "redis", "name": "Redis", "unit": "redis-server.service" }
  ],
  "store": {
    "repo": "https://github.com/1Panel-dev/appstore",
    "branch": "main",
    "mirror": "docker.1ms.run"
  }
}
```

### `services`

在「总览」页的关键服务卡片中展示，可逐个启停。

- `key`：仅允许小写字母、数字、连字符，最长 64 字符；
- `name`：展示名，最长 64 字符；
- `unit`：systemd 单元名，如 `postgresql.service`。

**副作用**：这些服务同时会被加入「安全关闭 WSL」的停止列表 —— 关 WSL 前先按顺序停掉它们，避免数据损坏。若某个服务**不应**随 WSL 一起停，就别把它写进这里，改用 `WPANEL_STOP_UNITS` 控制。

### `store`

对应界面「商店设置」，改动后立即生效：

- 改 `repo` 或 `branch` → 清空本地缓存并重新下载模板；
- 只改 `mirror` → 立即生效，不需要重新下载。

`mirror` 留空字符串表示直连 `docker.io`。

## `data/ai.local.json`

AI 助手配置，由界面写入，**不进 git**。

```json
{
  "baseUrl": "https://api.deepseek.com/v1",
  "apiKey": "sk-...",
  "model": "deepseek-chat"
}
```

- 三项均为必填；
- `baseUrl` 必须以 `http://` 或 `https://` 开头，末尾斜杠会被去掉；
- 界面里密钥留空保存时会发送占位符 `__KEEP__`，服务端识别后沿用已保存的密钥（不会把占位符写进去）；
- 密钥以**明文**存在本机磁盘，请自行保证该目录的访问权限。

## 其他运行时文件

| 路径 | 内容 | 是否进 git |
|---|---|---|
| `data/activity.jsonl` | 审计日志（超过 5MB 轮转为 `.1`） | 否 |
| `data/store-cache/` | 应用商店模板缓存与解压产物 | 否 |
| `data/import-*.tar` | 镜像导入的临时文件，用完即删 | 否 |
| `logs/controller.out.log` / `.err.log` | 控制服务标准输出 / 错误 | 否 |
| `logs/ui.out.log` / `.err.log` | 前端进程标准输出 / 错误 | 否 |

> 排障第一站永远是 `logs/` 目录。
